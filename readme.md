# 🚀 Instalare

Clonează repository-ul:

```bash
git clone https://github.com/VectorForge-prime/Weather-app.git
```

Intră în proiect:

```bash
cd Weather-app
```

Deschide:

```
index.html
```

sau pornește Live Server.
